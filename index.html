Treasure Code Practice

Help Laurel the Adventurer collect every purple gem. Build a program with blocks, press Run, and fix it if something goes wrong. Level 3 is the same puzzle as the test picture.

Meet the 5 blocks

move forward

Laurel walks one square the way she is facing.

turn right ↻

Laurel turns to her right. She stays on the same square.

turn left ↺

Laurel turns to her left. She stays on the same square.

collect

Picks up the gem. Use it only when Laurel is standing on a gem.

repeat 4 times

Does the blocks inside it again and again. It makes your code shorter.

Play

Workspace · tap a block above to add it
Tap blocks to build your program, then press Run.

When it goes wrong: debug!

1. Watch

Press Step to run one block at a time. The yellow box shows which block is working.

2. Find

Stop at the first block where Laurel does something wrong. Did she turn the wrong way?

3. Fix

Remove the wrong block with ×, add the right one, then Reset and Run again.

4. Shorten

See the same blocks again and again? Put them inside a repeat block.

How the test is scored

5 parts × 4 points = 20 points. Your score is points ÷ 20 × 100.
